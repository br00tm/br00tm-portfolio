## 💡 Sobre

Portfólio pessoal desenvolvido com **HTML, CSS e JavaScript puro** — sem frameworks, sem dependências. Um único arquivo `index.html`.

## ✨ Seções

- **Hero** — apresentação, roles e links rápidos
- **Sobre** — bio, stack e TCC
- **Skills** — tech stack completa por categoria
- **Projetos** — InfraWatch, GEC-Eventometro, NLP-DISCOGRAFY, Venda-Camisas
